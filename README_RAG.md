# 📚 바탕화면 docs 문서 기반 RAG 챗봇 시스템

코딩 초보자도 쉽게 사용할 수 있는 **문서 기반 RAG(Retrieval-Augmented Generation) 챗봇**입니다.  
사용자의 **바탕화면(`Desktop/docs`)** 폴더에 저장된 문서들을 자동으로 읽어 지식베이스를 구성하고, 질문에 대해 정확한 근거와 출처를 인용하여 답변합니다.

---

## 🌟 주요 특징

1. **2단계 멀티 서브 에이전트 파이프라인**:
   - 🔍 **Sub-Agent 1 (문서 검색 에이전트 - `retriever_agent.py`)**:  
     사용자의 질문 키워드와 문맥을 분석하여 수천 자의 문서 중에서 가장 관련성이 높은 핵심 본문 조각(청크)을 랭킹 점수와 함께 찾아냅니다.
   - ✍️ **Sub-Agent 2 (요약 및 답변 에이전트 - `generator_agent.py`)**:  
     검색 에이전트가 찾아온 조각들만을 근거로 삼아, 환각(지어내기) 없이 정확한 요약 답변을 작성하고 `[출처: 파일명, 청크 #]`를 명시합니다.

2. **코딩 초보자 친화적 설계**:
   - 외부 C++ 컴파일러나 복잡한 프레임워크 설치 없이 **파이썬 표준 라이브러리만으로 즉시 작동**합니다.
   - 더블 클릭 한 번으로 실행할 수 있는 `run.bat` 배치 파일이 포함되어 있습니다.

3. **다양한 문서 포맷 지원**:
   - `.txt`, `.md`, `.markdown`, `.docx` (내장 XML 파서로 즉시 지원), `.pdf` (pypdf 지원), `.csv`, `.json` 지원

4. **두 가지 인터페이스 제공**:
   - **웹 UI 브라우저 모드 (`app.py`)**: 깔끔하고 직관적인 대화창, 실시간 에이전트 추론 단계 표시, 문서 갱신 버튼 제공
   - **터미널 콘솔 모드 (`cli.py`)**: 가볍고 빠른 명령행 대화창

---

## 🚀 빠른 시작 가이드 (How to Run)

### 1. 문서 넣기
컴퓨터의 **바탕화면(`Desktop`)** 안에 있는 **`docs`** 폴더에 질문하고 싶은 문서 파일(`.txt`, `.docx`, `.pdf`, `.md` 등)을 자유롭게 넣어주세요.  
*(현재 바탕화면의 `스타트업 실패의 구체적인 원인 분석 by Gemini.docx` 파일이 자동으로 연결되어 있습니다.)*

### 2. 실행 방법

#### 방법 A (가장 추천 - 마우스 더블 클릭):
`run.bat` 파일을 마우스로 더블 클릭합니다.  
자동으로 웹 서버가 구동되고 브라우저(`http://localhost:8501`)가 열립니다.

#### 방법 B (터미널에서 웹 UI 실행):
```bash
python app.py
```
브라우저에서 `http://localhost:8501`로 접속합니다.

#### 방법 C (터미널 콘솔 대화 모드):
```bash
python cli.py
```

## 💡 유용한 팁

- **문서를 새로 추가하거나 수정한 경우**:  
  웹 화면 상단의 **`문서 다시 읽기`** 버튼을 누르거나, CLI 모드에서 `refresh`를 입력하면 프로그램을 재시작하지 않아도 즉시 새 문서를 학습합니다.
- **Gemini API 연동 (선택 사항)**:  
  환경 변수에 `GEMINI_API_KEY`를 설정하시면 더욱 고도화된 최신 생성형 AI 모델이 답변을 작성합니다. (설정하지 않아도 내장 로컬 엔진이 100% 정상 작동합니다.)
