# 🛡 대한민국 안전포털 (K-SAFETY)

안전 표시 색상(녹색/검은색/노란색) 테마 기반의 반응형 산업·생활 안전 공익 포털 웹 애플리케이션입니다.  
**Supabase 클라우드 데이터베이스(PostgreSQL)** 연동을 기본 지원합니다.

---

## ⚡ Supabase 데이터베이스 연동 방법 (3분 완료)

본 프로젝트는 Supabase PostgreSQL 데이터베이스와 완전 호환되도록 구성되어 있습니다.

### STEP 1. Supabase 프로젝트 생성
1. [Supabase](https://supabase.com)에 로그인 후 **New project**를 생성합니다.
2. 프로젝트 생성 완료 후 좌측 메뉴의 **SQL Editor**로 이동합니다.

### STEP 2. 테이블 스키마 및 초기 데이터 생성
1. 프로젝트 루트에 제공된 [`supabase-schema.sql`](./supabase-schema.sql) 파일의 전체 내용을 복사합니다.
2. Supabase의 **SQL Editor**에 붙여넣고 우측 하단 **Run** 버튼을 클릭합니다.
   - `site_settings` (홈페이지 간단 설정)
   - `users` (회원 가입 승인/거절 심사)
   - `posts` (일반 자료실 & 회원 전용 게시판)
   - `comments` (답변 및 댓글)
   - `qna` (관리자 수신함 및 공식 답변)
   - 기본 테스트 데이터 및 RLS 보안 정책이 자동 생성됩니다.

### STEP 3. 환경 변수(`.env`) 입력
1. Supabase 대시보드 좌측 하단 **Project Settings** > **API** 메뉴로 이동합니다.
2. **Project URL**과 **Project API Keys (anon public)** 값을 확인합니다.
3. 프로젝트 루트의 `.env` 파일을 열고 다음과 같이 입력합니다:

```env
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_KEY=your-actual-supabase-anon-key-here
PORT=3000
```

### STEP 4. 서버 시작
```bash
npm start
# 또는 node server.js
```
- 터미널에 `[Database] Supabase Cloud DB 연동 완료` 메시지가 출력되며 Supabase 클라우드 DB로 동작합니다.
- 만약 아직 `.env`에 키를 넣지 않은 상태라면 자동으로 로컬 개발 스토어로 동작하여 언제든 끊김 없이 테스트할 수 있습니다.

## 📌 주요 요구사항 구현 내역

### 1. 레이아웃
1. **심플한 안전 색상 배색 (녹색 / 검은색 / 노란색)**
   - **Safety Green (`#059669`)**: 안전 확인, 기본 수칙, 정상 작동, 가입 승인
   - **Safety Black (`#111827`)**: 헤더, 기본 대비, 중요 지침, 비상 규정
   - **Safety Yellow (`#F59E0B`)**: 위험 주의, 회원 전용 강조, 긴급 알림 배너, 안전 빗금(Hazard Stripe)
2. **첫 페이지 안전 관련 공익 정보 표시**
   - 3대 핵심 산업안전 수칙 (추락 예방, 끼임 예방, 보호구 100% 착용)
   - 화재 및 비상상황 발생 시 4단계 골든타임 행동요령
   - 실시간 긴급 비상연락망 (119 소방구조, 1588-0075 산재신고 등)
   - 누구나 바로 열람 가능한 최신 안전 공익 매뉴얼
3. **하단 Footer 상에 관리자 모드 진입 로그인 메뉴 추가**
   - 사이트 하단 푸터 우측에 `🔒 관리자 모드 로그인` 전용 진입 메뉴 배치
   - 관리자 로그인 시 즉시 대시보드로 다이렉트 이동

### 2. 권한 및 3대 모드 분리

#### 2-1. 관리자 모드 (Admin)
- **Q&A 수신함**: 방문자 및 회원이 관리자에게 보낸 모든 질의사항을 수신하고, 공식 답변 작성/수정
- **회원 가입 승인/거절**: 가입 신청자의 자격을 심사하여 [승인] 또는 [거절] 처리 (승인된 회원만 회원 전용 기능 이용 가능)
- **모든 게시판 수정/삭제 권한**: 일반 안전자료실 및 회원 전용 게시판의 모든 게시글/댓글을 수정 및 영구 삭제할 수 있는 슈퍼 권한
- **홈페이지 수정 권한 (간단한 사항)**: 첫 페이지 메인 표어, 서브 슬로건, 긴급 비상연락처, 상단 긴급 알림 띠배너, 푸터 문구 즉시 변경 및 실시간 반영

#### 2-2. 회원 모드 (Member)
- 관리자 승인이 완료된 정회원 계정
- **회원 전용 게시판**: 현장 안전 개선 제안, 위험성평가 토론, 아차사고 공유 글쓰기 및 답변(댓글) 작성 가능
- **안전 Q&A**: 관리자에게 1:1 비밀/공개 문의 작성 및 본인 문의 답변 확인

#### 2-3. 비회원 모드 (Guest)
- **일반 게시판 자료 열람**: 기본수칙, 비상대응 요령 등 공익 안전 자료실 열람
- **회원가입 신청**: 가입 신청서 제출 시 '관리자 승인 대기' 상태로 등록
- **안전 Q&A 접수**: 비회원도 성명/이메일을 기재하여 관리자에게 안전 관련 문의 가능
